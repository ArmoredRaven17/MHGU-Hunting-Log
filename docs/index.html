How this works

  • Pick a quest on the left — search by quest name or monster, or browse by rank.
  • The quest fills in its own locale and objective; everything else is yours to write.
  • Save Entry adds it to the logbook on the right. Click any entry to edit it again.
  • Farming the same quest? Turn on Farming and the form stays filled after each save, so back-to-back runs only need whatever actually differed.
  • Already saved a run and want another like it? Open it, change what differed, and press Save as New to file it as a second hunt instead of overwriting the first.
  • Tick entries and press Copy Selected to put them on the clipboard — handy for pasting a session into Discord. Shift-click a second tick box to take everything in between; All ticks the whole log.

Saving

  • The log saves itself in this browser as you type — including the entry you're part-way through writing, which is waiting for you when you come back.
  • Save writes it out to a .json file and Open loads one back. Keep separate files for separate playthroughs.
  • Clearing your browser's site data wipes the in-browser copy, so keep a file if the log matters.

Other MHGU Apps

Companion fan tools by the same author. Each opens in a new tab.

  • Quest Randomizer Rolls random quests when you can't decide what to hunt.
  • Collection Tracker Tracks which weapons, armor and Palico gear you own, and what it costs to finish them.
  • Equipment Box Mirrors the in-game box — 2000 hunter slots and 1000 Palico — so you can plan where things sit.
  • Bingo Builds a bingo card of hunting goals, with a shareable seed so a group can race the same board.
  • Hunting Log you are here Keeps a running record of your hunts — what you were after, what you wore, who came along.
  • Zenny Gauntlet A scored challenge run — fail a hunt or get carted and you lose that weapon/style combo for the rest of the run.
  • Set Builder Assemble a full set by hand and see exactly which skills it activates.
  • Monster Info Hitzone charts for every monster — where to hit and with what.
